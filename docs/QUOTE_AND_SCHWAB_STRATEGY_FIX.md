# Quote reliability and Schwab strategy naming fix

## Quote reliability

The quote/history provider order is now:

1. Tradier when a token is configured.
2. Yahoo public v8 chart endpoint (`query1`, then `query2`).
3. Stooq completed daily CSV (`stooq.com`, then `stooq.pl`).
4. yfinance library calls as a final fallback.

The direct Yahoo chart path does not rely on yfinance cookie/crumb requests. The UI no longer renders an unavailable provider response as `$0.00`; it displays **Unavailable** and blocks the trade instead.

## Charles Schwab strategy names

The strategies currently generated by the engine now use the labels shown in Schwab:

| Engine structure | Schwab strategy label |
|---|---|
| One long call | Call |
| One long put | Put |
| Bull call debit spread | Vertical Call |
| Bear put debit spread | Vertical Put |

The engine does not claim to support the other Schwab menu strategies until their complete leg construction, pricing, risk, and qualification logic is implemented.
